# Demo script

1. Start Compose and sign in using the configured super-admin email/password.
2. Create a student account and submit an institution registration using an authorized college URL.
3. Approve the application and copy the generated one-time admin password from the approval result.
4. Sign in as that college admin; add a fact such as category “admissions”, title “Office hours”, value from the official site.
5. Sign in as a student, type the college code, then ask about the saved fact. Check its source badge and source link.
6. Trigger a crawl and inspect progress and resulting page evidence in the admin view.

Use only real college authorization and real official data. Do not put demonstration credentials or fabricated college records in the deployed database.
